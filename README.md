# INST 405 Final Project: Doomwoken
## INST 405 Final project: Game created using GameMaker and GML language 
## Background:
INST 405 is a Game Design course available for undergrad and grad students at the University of Maryland. Using our understanding of what makes a game a game, we developed a mini open-world RPG game using GameMaker and its own coding language, GML. I was the main developer of this project. We only had 3 weeks to create a somewhat functional game and this was the result of my first time coding for games.
